- `evi-longodja` : LOMBI Evy, chargé de communication dans les statuts. La correspondance avec le fichier source `Evi longodja.jpg` est confirmée par l’utilisateur.

Source des fonctions : `LAB CONGO Statuts.docx FINAL 5.docx`, listes des membres chargés de la direction et annexes. Le document source reste local ; seules les informations nécessaires à la présentation de l’équipe sont reprises.
