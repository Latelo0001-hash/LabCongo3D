# Modèles illustratifs LabCongo

`microscope.glb`, `laboratory.glb` et `transport-crate.glb` sont des créations géométriques originales produites par `scripts/generate-models.mjs` avec Three.js. Aucun modèle externe ni texture distante. Ces illustrations ne décrivent pas un équipement livré ni une école existante.

Recréer avec `npm run models:generate`. Format GLB (glTF 2.0), matériaux PBR, géométries partagées par l’exporteur, pas de décodeur ou service distant. Ils peuvent être remplacés par des modèles définitifs en conservant des dimensions comparables. La scène reste statique sans WebGL, lors d’une erreur ou avec réduction des animations.
